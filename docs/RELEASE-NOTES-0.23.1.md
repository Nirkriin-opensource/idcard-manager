# IDcard Manager 0.23.1

Correct the application and public hosting package name to **IDcard Manager**. The repository is now `Nirkriin-opensource/idcard-manager`, and the hosting archive is `idcard-manager-0.23.1.tar.gz`.

Includes the installer, all ten migrations, MIT license, dependency lockfile, SBOM, source manifest and checksums. First-admin setup uses a unique temporary password with a required change. Installation requires internet access.

Follow [HOSTING.md](HOSTING.md). HTTPS, protected administration, encrypted off-server backups, recovery testing and independent security assessment remain required before unrestricted public deployment. This release does not claim security certification.
