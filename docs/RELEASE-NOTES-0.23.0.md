# Multipurpose Card Manager 0.23.0

Initial public MIT-licensed hosting package for Ubuntu 22.04/24.04 LTS.

- Native web/worker/PostgreSQL/Caddy/systemd installer and operator controls.
- General card workflow, configurable required fields, shared templates, front/back designer, themes, branding and multilingual printing.
- People imports, shareable profession forms, admin review, photo uploads and bulk matching.
- Background generation, PNG/JPG/PDF/ZIP exports, print sheets, verification and card lifecycle history.
- People/Photos selection and recoverable deletion, archive/restore templates and previewed administrator-only permanent purge.
- First-admin setup with a unique temporary password and mandatory first-login password change.
- Package includes all migrations, pinned dependency lockfile, MIT/third-party notices, CycloneDX SBOM, file manifest and checksums. Runtime data and local delivery reports are excluded.
- Release metadata now lists all ten migrations. Type checking generates Next.js route types for a clean checkout.

Download the source archive and checksum file, then follow `docs/HOSTING.md`. Installation requires internet access and a dedicated Ubuntu host. No live database, uploaded photos, account passwords, backups or preconfigured tenant is distributed.

This release does not claim independent security certification or completed physical printer/fresh-server acceptance. Public internet deployment requires HTTPS, protected administration, encrypted off-server recovery, privacy/retention policies and independent security assessment. See the included public-launch review.
